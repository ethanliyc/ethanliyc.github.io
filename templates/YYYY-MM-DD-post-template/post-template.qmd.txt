# Workflow 

When editing **few articles**, to make it render faster, run the following to **render only the updated articles** and see preview (updates whenever the qmd changes)
```bash
quarto preview
```

See [maintainers' discussion thread](https://github.com/orgs/quarto-dev/discussions/3674#discussioncomment-4403913). This is still being developed as of 2025-08. Rendering all files seems still necessary now.


When the editing is finished, you still need to render everything: 
```bash
quarto render
quarto preview # optional

git status 
git add .
git commit -m "Some messages"
git push
```

## Common Text Formatting Syntax

- `<br>`: Add a while space to separate paragraphs: 
- `---`: Add separation line: 
- @sec-secname @fig-figname: cross-reference those objects (if labeled). The prefix are reserved, you **cannot use whatever prefix**. The reserved ones are sec, fig, tip, nte, tbl, etc. See [Quarto Cross-Ref](https://quarto.org/docs/authoring/cross-references.html)

## Lists

    1. **4 spaces before this**
    2. Nested sub-step B.


### Outline / Checklist (Unordered List)

- Main task or concept
    - Subtask / detail
        - Even more specific note
- Another task
- Final takeaway
